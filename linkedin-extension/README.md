# Revenue OS für LinkedIn (Chrome-Erweiterung)

Unten rechts auf LinkedIn erscheint der Button **⚡ Revenue OS**:

- **Auf einem Profil** (`linkedin.com/in/…`): zeigt, ob die Person schon im CRM ist (Lead/Deal-Status, nächste Aufgabe).
  **In Revenue OS speichern** legt Kontakt + Firma an (oder aktualisiert sie), optional einen Lead in *Outreach* und eine Follow-up-Aufgabe.
- **In einer Nachricht** (`linkedin.com/messaging/…`): **Nachricht loggen** speichert die letzte Nachricht (oder markierten Text) als Aktivität.
  Eine *Antwort* der Person schiebt den Lead automatisch von *Outreach* auf *Im Gespräch*.

Die Erweiterung liest nur die sichtbare Seite und nur, wenn du klickst. Sie nutzt deine Revenue-OS-Anmeldung (gleiche Rechte wie in der App).

## Installation

1. Ordner `linkedin-extension` herunterladen (oder `revenue-os-linkedin.zip` entpacken).
2. Chrome → `chrome://extensions` → oben rechts **Entwicklermodus** an.
3. **Entpackte Erweiterung laden** → den Ordner `linkedin-extension` wählen.
4. Einmal in https://revenue-os-chi.vercel.app anmelden – fertig. LinkedIn-Tab neu laden.

Updates: neue Dateien in den Ordner kopieren und auf `chrome://extensions` bei der Erweiterung ↻ klicken.
